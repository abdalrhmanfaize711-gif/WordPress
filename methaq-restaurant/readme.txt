Displays an Arabic RTL restaurant website using content from a Strapi v4 REST API.

== Installation ==
1. Upload methaq-restaurant.zip under Plugins > Add New > Upload Plugin.
2. Install and activate the plugin.
3. Configure the Strapi base URL and optional read-only API token in Settings > Methaq Restaurant.
4. Add [restaurant_home] to a page and set it as the static homepage.

== Shortcodes ==
[restaurant_home]
[restaurant_menu]
[restaurant_info]
[restaurant_contact]

== Notes ==
Requires Strapi v4 REST response structure and the content types described in the repository setup guide.
