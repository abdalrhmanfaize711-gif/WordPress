Displays an Arabic RTL restaurant website using content from a Strapi v4 REST API.

== Installation ==
1. Upload methaq-restaurant.zip under Plugins > Add New > Upload Plugin.
2. Install and activate the plugin.
3. The plugin automatically creates Home, Menu, About and Contact pages.
4. Before Strapi is connected, the homepage displays a clearly marked preview.
5. Configure the Strapi base URL and optional read-only API token in Settings > Methaq Restaurant.

== Shortcodes ==
[restaurant_home]
[restaurant_menu]
[restaurant_info]

== Notes ==
Requires Strapi v4 REST response structure and the content types described in docs/SETUP.md.
