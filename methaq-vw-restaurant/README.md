# Methaq Restaurant — Child Theme

This is a customized child theme based on **VW Restaurant Lite** from the official WordPress.org theme directory.

## Parent theme requirement
Install and activate the free parent theme **VW Restaurant Lite** first:
https://wordpress.org/themes/vw-restaurant-lite/

Then upload this child theme ZIP from **Appearance → Themes → Add New → Upload Theme** and activate **Methaq Restaurant**.

The child theme preserves the parent theme's header, footer and theme framework while applying the Methaq brand palette, Arabic RTL layout refinements and a restaurant landing-page template.

## Strapi integration
Keep the **Methaq Restaurant — Strapi Connector** plugin installed and activated. It creates Home, Menu, About and Contact pages and supplies dynamic restaurant/menu content through shortcodes. Once the child theme is activated, the plugin can automatically assign its generated pages to the theme's primary navigation location if there is no menu already assigned.

## Customization
- Parent theme: VW Restaurant Lite.
- Brand colors: olive green, warm cream and muted orange.
- Language/layout: Arabic RTL.
- Homepage sections and menu items: read from Strapi through the connector plugin.
- Before Strapi is configured, the connector displays a marked sample preview.
