# Methaq Restaurant — Child Theme

This is the customized child theme based on **VW Restaurant Lite**, a ready-made restaurant theme from the official WordPress.org directory.

## Parent theme requirement
Install the free parent theme **VW Restaurant Lite** first:
https://wordpress.org/themes/vw-restaurant-lite/

Then upload this child theme ZIP from **Appearance → Themes → Add New → Upload Theme** and activate **Methaq Restaurant**.

The child theme preserves the parent theme framework and customizes the brand palette, Arabic RTL presentation and homepage styles.

## Content plugin
Install and activate the **Methaq Restaurant — Display Website** plugin. The plugin creates the restaurant pages and stores all restaurant/menu information inside WordPress. No Strapi, external CMS or API is used.

## Customization
- Parent theme: VW Restaurant Lite.
- Brand colors: olive green, warm cream and muted orange.
- Language/layout: Arabic RTL.
- Restaurant menu and contact details: stored locally in WordPress and edited from the **موقع المطعم** admin menu.
- The child theme controls presentation; the plugin supplies the restaurant content.
